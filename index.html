Hello!

The links under “Photographic Experiments & Reflections” will take you to some analogue film experiments that I've been working on, accompanied by some notes/reflections that emerged from that work. (Be warned, this is still a work in progress, so some of the reflections are really more like stream-of-consciousness vibes).

The link under “Interactive Photo Project” will take you to a program that I have been developing as part of/in response to these ongoing experiments. The program lets you make a double exposure with me by pairing an image you upload with a photo from the base library. I started the library with my own photos, some analogue, others digital. You may also choose to leave any image(s) that you upload to become part of the library of base photos upon which new double exposures can be made.
